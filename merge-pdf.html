How Merging PDFs Works

This tool copies every page from each PDF you add into one new PDF, in the order the files appear in the list. It's useful for combining multiple scanned documents, invoices, or chapters into a single file before sharing.

1
Add your PDFs. Click the box above or drag and drop two or more PDF files.
2
Set the order. Use the ↑ / ↓ buttons next to each file to arrange them in the order you want them merged.
3
Merge. Click "Merge PDFs." All pages from every file are combined into one new PDF, preserving the original page content and quality.
4
Download. Your merged PDF is generated in your browser and downloaded straight to your device.

Because pages are copied directly rather than re-rendered as images, the merged PDF keeps the original text, links, and quality of every source file.
